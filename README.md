# PEMTEKS - Text Similarity

This project explores text similarity techniques using Python. It covers Cosine Similarity and Jaccard Similarity to measure the similarity between text documents using TF-IDF and binary text representations.

The project also implements text preprocessing for Indonesian news articles using NLTK and Sastrawi, including lowercasing, stopword removal, and stemming. TF-IDF is then used to represent the processed documents and retrieve relevant articles based on their similarity to a given search query.

## Requirements

This project uses Python and can be run in Google Colab or Jupyter Notebook. The required libraries include pandas, scikit-learn, nltk, Sastrawi, scipy, and numpy.
